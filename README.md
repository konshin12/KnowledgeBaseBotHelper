# Telegram-бот: База знаний для поддержки клиентов (L1/L2)

## Описание проекта

Инструмент для автоматизации работы операторов технической поддержки. Бот выступает в роли интерактивного справочника, предоставляя быстрый доступ к регламентам (процедурам), шаблонам ответов, расшифровке аббревиатур и справочным материалам.

Проект решает задачи по снижению времени обработки обращений (AHT), стандартизации качества коммуникации с клиентами и ускорению адаптации новых сотрудников (онбординг).

## Бизнес-ценность

* **Снижение времени поиска информации.** Оператору не требуется удерживать в памяти десятки скриптов и регламентов — все данные доступны в пару кликов.
* **Стандартизация ответов.** База шаблонов исключает неверные формулировки при общении с клиентами в сложных ситуациях (списания, безопасность, задержки).
* **Оптимизация онбординга.** Структурированные алгоритмы действий (Процедуры) упрощают процесс обучения и ввода в должность новых специалистов.

## Технологический стек

* **Язык программирования:** Python 3.12
* **Фреймворк:** Aiogram 3.x (асинхронный)
* **Дополнительные библиотеки:** `python-dotenv`, `aiohttp-socks`

## Архитектура проекта

* `main.py` — точка входа, инициализация бота, настройка сессии (поддержка прокси) и запуск polling.
* `config.py` — конфигурация проекта, текстовые данные и структуры (словари, списки) для наполнения бота.
* `handlers.py` — обработчики событий. Реализована оптимизированная маршрутизация callback-запросов (паттерн "Словарь-маппинг"), что позволило избежать дублирования кода и упростить масштабирование.
* `keyboards.py` — динамическая генерация Reply и Inline-клавиатур.
