# Telegram-бот: База знаний для поддержки клиентов L1

## 📌 О проекте
Инструмент для автоматизации работы операторов поддержки. Бот выступает в роли интерактивного справочника, предоставляя быстрый доступ к шаблонам ответов, регламентам (процедурам), расшифровке аббревиатур и полезным ссылкам. 

Проект создан для снижения времени обработки обращений (AHT) и стандартизации качества коммуникации с клиентами.

## 🎯 Решаемые проблемы (Business Value)
* **Снижение времени поиска информации:** Оператору не нужно держать в голове десятки скриптов — все доступно в пару кликов.
* **Стандартизация ответов:** База шаблонов (кэшбэк, списания, безопасность) исключает неверные формулировки при общении с клиентами.
* **Онбординг:** Упрощает адаптацию новых сотрудников за счет структурированных алгоритмов действий (Процедуры).

## 🛠 Технологический стек
* **Язык:** Python 3.12
* **Фреймворк:** Aiogram 3.x (асинхронный)
* **Дополнительно:** `emoji`, `python-dotenv`

## ⚙️ Архитектура
* **`main.py`** — точка входа, инициализация бота и запуск polling.
* **`handlers.py`** — обработчики событий. Реализована оптимизированная маршрутизация (callback-запросы), что позволило избежать дублирования кода.
* **`keyboards.py`** — динамическая генерация Reply и Inline-клавиатур.
* **`config.py`** — конфигурация и хранение данных (списки шаблонов, процедур, словарей).

## 🚀 Запуск проекта
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Создайте файл `.env` в корне и укажите ваш токен: `BOT_TOKEN=your_token_here`
4. Запустите бота: `python main.py`
